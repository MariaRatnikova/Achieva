# Achieva

Achieva is a web-based productivity application designed to help students organize their academic workload efficiently.  
It combines a task management system, calendar visualization, and a structured start screen to improve clarity and planning.

---

## Overview

Academic life often involves managing multiple modules, assignments, and deadlines at the same time.  
Achieva provides a centralized interface where students can plan tasks, track deadlines, and visualize their schedule in a structured and intuitive way.

The project focuses on usability, clean interface design, and clear interaction logic.

---

## Core Features

- Structured start screen with navigation  
- To-do list for task management  
- Calendar view (month and week)  
- Deadline visualization  
- Modal-based creation of tasks and deadlines  
- Local data persistence using localStorage  

---

## Tech Stack

### Frontend

### Architecture
- Modular JavaScript structure
